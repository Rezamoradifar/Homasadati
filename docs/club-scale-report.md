# آزمون مقیاس شبکه هما نت

زمان اجرا: 2026-10-10T12:14:46.093Z

هر حساب آزمایشی یک خرید پرداخت‌شده ۷۰ میلیون تومانی دارد و ۷ جایگاه آن فعال است. چیدمان متعادل با هشت ورودی و چیدمان متمرکز در چپ با دو ورودی بررسی شد. اطلاعات بانک و کاربران واقعی استفاده نشده است.

| حساب | جایگاه | چیدمان | تسویه (ثانیه) | P95 نقشه (ms) | P95 HTTP (ms) | خطاهای HTTP |
|---:|---:|---|---:|---:|---:|---:|
| 1,000 | 7,000 | متعادل | 1.02 | 10.89 | 42.88 | 0/120 |
| 10,000 | 70,000 | متعادل | 11.66 | 96.83 | 353.92 | 0/120 |
| 1,000 | 7,000 | متمرکز در چپ | 0.87 | 7.12 | 32.34 | 0/120 |

برای هر سناریو ۱۲۰ درخواست HTTP محلی با همزمانی ۶ به مسیرهای نقشه، جست‌وجو، گزارش و دعوت فرستاده شد. نشست واقعی برنامه استفاده شد؛ درخواست بدون نشست باید ۴۰۱ برگرداند. این سرور آزمایشی از handler واقعی استفاده می‌کند و Next.js، Nginx، Cloudflare و اینترنت عمومی را شامل نمی‌شود.

آزمون مستقل، تمام سفارش‌ها، حجم باقی‌مانده هر سمت و جایگاه، سقف هفتگی، نقدی، ووچر، فلش و تکرارنشدن پرداخت را کنترل می‌کند. هش‌های منابع آزمون در فایل JSON ثبت شده‌اند.

اولین اجرای ۱۰هزار حساب قبل از بهینه‌سازی آماده‌سازی SQL، با SIGKILL متوقف شد و نتیجه موفق محسوب نمی‌شود. در اجرای اولیه ۱۰۰۰ حساب، تسویه ۸٫۶۶ ثانیه زمان برد. کش محدود دستورهای آماده SQL، داده یا پارامترهای کاربران را کش نمی‌کند؛ نقشه نیز حجم هفت جایگاه را با یک کوئری تجمیعی می‌خواند.

این سناریوها اثبات درآمد، پایداری همه چیدمان‌ها یا ظرفیت سرور اصلی نیستند. توقف یا کندی کاربران واقعی هنوز به آزمون جداگانه روی مسیر شبکه و سرور نیاز دارد.

اجرای مجدد:

```bash
npm run platform:simulate -- 1000 10000
npm run platform:simulate -- 1000 --shape left-heavy --output docs/club-scale-left-results.json
python3 scripts/render-club-scale-report.py
```
