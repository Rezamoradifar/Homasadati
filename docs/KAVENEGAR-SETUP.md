# ثبت کاوه‌نگار روی سرور موجود هما

این ابزار فقط تنظیمات اتصال پیامک را در دیتابیس موجود ثبت می‌کند. اجرای آن به
استقرار شاخهٔ جدید، نصب بسته، اجرای `platform:setup` یا راه‌اندازی مجدد نیاز ندارد.

## اجرا

فایل مستقل [kavenegar-setup.py](../scripts/kavenegar-setup.py) را ابتدا دریافت و
سپس در ترمینال تعاملی **سرور هما** اجرا کنید. دستور زیر نسخه‌ای را دریافت
می‌کند که محتوای آن با SHA-256 مشخص تأیید می‌شود. در دستور انتشار نهایی، نشانی
دانلود به کامیت مشخص پین شده است.

```bash
cd /opt/homay/app &&
homay_sms_dir="$(mktemp -d)" &&
curl --fail --location --proto '=https' --tlsv1.2 --connect-timeout 15 --max-time 60 \
  'https://raw.githubusercontent.com/Rezamoradifar/Homasadati/codex/homay-kavenegar-setup/scripts/kavenegar-setup.py' \
  -o "$homay_sms_dir/kavenegar-setup.py" &&
printf '%s  %s\n' \
  '95839a964c98555a201f00c129281f9e994762ad48fcd047333868868cc51881' \
  "$homay_sms_dir/kavenegar-setup.py" | sha256sum -c - &&
sudo python3 "$homay_sms_dir/kavenegar-setup.py"
```

پیش‌نیازها: سرور `vps-astra-1758`، مسیر `/opt/homay/app`، کاربر `homay`،
سرویس‌های فعال `homay` و `homay-worker`، systemd با cgroup v2، Python 3.9 یا
جدیدتر و بسته‌های Node نصب‌شدهٔ خود پروژه. ابزار از Node پردازش فعال استفاده می‌کند.
این فایل باید در یک ترمینال تعاملی SSH اجرا شود، نه از طریق pipe یا اجرای زمان‌بندی‌شده.
کلید API در فایل اجرایی و مخزن وجود ندارد؛ ابزار آن را هنگام اجرا دریافت می‌کند.
دانلود و انتشار این ابزار به‌تنهایی تنظیمات سرور را تغییر نمی‌دهد.

ابزار کلید API را با ورودی بدون نمایش دریافت می‌کند. کلید را در آرگومان دستور،
فایل، متغیر محیطی، گفت‌وگو یا مخزن قرار ندهید. اگر کلیدی را قبلاً به اشتراک
گذاشته‌اید، کلید جایگزین را مستقیماً در همین ورودی وارد کنید.

نام الگوی مورد انتظار **`HomanetsOTP`** است. الگو باید در کاوه‌نگار تأییدشده،
پیامکی و دارای تنها پارامتر `%token` باشد. ابزار فقط API خواندن فهرست الگوها را
فراخوانی می‌کند؛ الگو نمی‌سازد و پیامک آزمایشی نمی‌فرستد.

## نتیجه

در صورت موفقیت این نشانگر نمایش داده می‌شود:

```text
KAVENEGAR_CONFIG_SAVED
```

این نتیجه یعنی کلید و نام الگو ذخیره و بازخوانی شده‌اند. تحویل پیامک، اعتبار
حساب ارائه‌دهنده و فرایند کامل ورود هنوز باید با شمارهٔ آزمایشی مجاز بررسی شوند.

اگر `PendingReview` نمایش داده شد، هیچ تنظیمی ذخیره نشده است. پس از تأیید
الگو در پنل کاوه‌نگار، همان دستور را دوباره اجرا کنید. اجرای مجدد با همان کلید
و الگو، تنظیمات را بی‌دلیل بازنویسی نمی‌کند.

اگر شمارهٔ فرستندهٔ اعلان از قبل تنظیم شده باشد، ذخیرهٔ کلید می‌تواند ارسال
عادی اعلان‌های صف‌شده یا جدید worker را نیز فعال کند. ابزار این وضعیت را
قبل از دریافت کلید توضیح می‌دهد و شمارهٔ فرستنده را تغییر نمی‌دهد.

## بررسی‌های پیش از ثبت

- پردازش واقعی هر سرویس از cgroup همان سرویس پیدا می‌شود؛ `MainPID` به‌تنهایی
  به‌عنوان پردازش وب فرض نمی‌شود، چون ممکن است یک wrapper مربوط به npm باشد.
- محیط اولیهٔ پردازش و فایل‌های محیطی production با `@next/env` موجود بازسازی
  می‌شوند. فایل محیطی با زمان تغییر جدیدتر از شروع سرویس باعث توقف می‌شود.
- دیتابیس بازِ هر سرویس با شناسهٔ فایل در `/proc` تطبیق داده می‌شود؛ مسیر
  دیتابیس و کلید رمزگذاری وب و worker باید یکسان باشند.
- تغییر سرویس، فایل محیطی یا تنظیمات در فاصلهٔ بررسی تا ثبت باعث توقف می‌شود.
- اتصال SQLite با `fileMustExist` باز می‌شود؛ جدول یا دیتابیس جدید ساخته نمی‌شود.
- رمزگذاری AES-256-GCM با کلید اصلی موجود و قالب خود سایت انجام می‌شود؛
  ماژول‌های مهاجرت و راه‌اندازی برنامه وارد نمی‌شوند.
- تنها `kavenegar_key` و `sms_template` در یک تراکنش ثبت می‌شوند. شمارهٔ
  فرستنده نیز در مقایسهٔ هم‌زمانی کنترل می‌شود، ولی تغییر نمی‌کند.
- کلید و اطلاعات خصوصی subprocess یا خطاهای شبکه در خروجی نمایش داده نمی‌شوند.
- عملیات دیتابیس با کاربر `homay` انجام می‌شود. تغییر نسخهٔ Git، توقف سرویس و
  ارسال پیام در این ابزار وجود ندارد.

## آزمون آفلاین

```bash
HOMAY_TEST_PROJECT="$PWD" python3 -m unittest discover -s scripts/tests -p 'test_kavenegar_setup.py' -v
```

فرمان آزمون را در ریشهٔ پروژه، پس از نصب وابستگی‌های پروژه، اجرا کنید.
متغیر `HOMAY_TEST_PROJECT` مسیر مرجع سازگاری با کد برنامه را مشخص می‌کند.
آزمون‌ها از کلیدهای ساختگی، دیتابیس موقت و پاسخ‌های شبیه‌سازی‌شده استفاده می‌کنند.
آزمون سازگاری رمزگذاری، تابع `decrypt` واقعی پروژه را بررسی می‌کند.

مرجع ارائه‌دهنده: [مستندات رسمی کاوه‌نگار](https://kavenegar.com/rest.html)،
بخش مدیریت الگوهای اعتبارسنجی و `verify/templatelist`.
